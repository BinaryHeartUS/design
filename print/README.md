# Print

Print pieces are self-contained HTML files, with fonts and images embedded, exported to PDF from Chrome.

- `posters/` holds the Fall 2026 NU first-meeting poster, plus its window variant (HTML source and PDF).
- `flyers/` holds the Fall 2026 NU recruiting flyer (HTML and PDF).
    - `flyers/reference/` holds the Technician and Operations team flyers.
- `shipping-label/shipping-label.html` is the 4×6 label for moving devices between chapters.
    - Click any text to edit it, then print.

To export, open the file in Chrome and choose Print, then Save as PDF, with margins set to None and "Background graphics" turned on.
Never commit real names or addresses on labels.
